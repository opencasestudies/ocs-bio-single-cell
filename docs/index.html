What are the data?

“Raw” Data is available 3 different ways for this project.

  1. The .fastq files are available on SRA, with instructions on how they were aligned and counted using salmon alevin available on the GitHub.
  2. Slightly processed matrix files, separated for each of the 6 samples, available on GEO.

Dimensions: Rows and columns

Rows correspond to features – another term for genes. At this point though, they may represent exons or introns since we’re working with single nuclear data.

Columns correspond to droplets – right now they’re termed “droplets” because we may have empty droplets or doublets. After filtering, these droplets can also be termed nuclei for snRNA-seq data because we assume we’ve removed the droplets without single nuclei.

What are the dimensions of the object?

dim(snrna_data)
[1] 87308 65989

So that’s 87,308 features and 65,989 droplets.

By the time that we’re done with filtering, we expect to have a lot more nuclei than we do genes. This is because single cell data is very sparse typically. More on this later (even within this exploration section), but briefly:

  • Genes currently in the SingleCellExperiment object could represent mitochondrial genes – we don’t want those because we’re working with single nuclear data

  • Genes also may be listed more than once right now – exon and intron versions
  • There could be non-informative genes (low or no counts across droplets)

We will be filtering out some droplets (empty from ambient RNA detection and doublets from doublet detection), but filtering resources advise liberally keeping droplets when possible.

rowSums … what does it represent? quantiles?

rowSums() is representing the sum of counts for a feature across droplets.

quantile(rowSums(assays(snrna_data)$counts))
0%          25%          50%          75%         100%
0.0000       0.0000      20.0000     883.4077 4036226.0377

We see that some features have 0 counts across droplets. These are non-informative features where we won’t be able to distinguish expression levels or patterns and how they might change according to condition, diagnosis, or treatment. Genes with consistently low counts (greater than 0) can still be non-informative, so often researchers will use a threshold approach to make sure that a sufficient number of droplets have at least a certain number of a counts (or greater) for features and filter out ones that don’t. A rowSums approach is necessary for this, and while it is still summing counts, those counts are compared to a threshold such that the following example will return a sum of TRUEs (1’s) and FALSEs (0’s) which are reporting if the observed number of counts is greater than the observed for each droplet for each feature. Handling Introns and Exons

# Extract Exon Ensembl IDs and associated count data
exon_ids <- rowData(snrna_data) %>%
     as.data.frame() %>%
     dplyr::filter(!grepl("-I", gene_id)) %>%
     pull(gene_id)

exon_data <- snrna_data[exon_ids]

# Extract Intron Ensembl IDs and associated count data
intron_ids <- rowData(snrna_data) %>%
     as.data.frame() %>%
     dplyr::filter(grepl("-I", gene_id)) %>%
     pull(gene_id)

intron_data <- snrna_data[intron_ids]

# Simplify Ensembl IDs and find matching IDs between introns and exons

pattern_to_remove <- "\\..*"
replace_string <- ""

## the IDs
exon_ids <- sub(pattern_to_remove, replace_string, exon_ids)
intron_ids <- sub(pattern_to_remove, replace_string, intron_ids)

## the data sources
rownames(exon_data) <- exon_ids
rownames(intron_data) <- intron_ids
rownames(snrna_data) <- sub(pattern_to_remove, replace_string, rownames(snrna_data))

# Subset to only exons and introns with the same Ensembl ID
same_ensembl <- intersect(exon_ids, intron_ids)

# Remove introns and exons with shared IDs from the overall snRNA data
snrna_data_ids_subset <- rownames(snrna_data) %>%
  as.data.frame() %>%
  dplyr::filter(!. %in% same_ensembl) %>%
  pull(.)

# A new SingleCellExperiment object was created, where the sum
# of the UMI counts of spliced mRNA and introns sharing the same
# Ensembl ID was added.
sce <- SingleCellExperiment(assays = list(counts = rbind(counts(snrna_data[snrna_data_ids_subset]),
    counts(exon_data[same_ensembl]) + counts(intron_data[same_ensembl]))))

# Add back column and row data
colData(sce) <- colData(snrna_data)
rowData(sce) <- rbind(rowData(snrna_data) %>%
                        as.data.frame() %>%
                        dplyr::filter(rownames(.) %in% snrna_data_ids_subset),
                      rowData(snrna_data) %>%
                        as.data.frame() %>%
                        dplyr::filter(rownames(.) %in% same_ensembl)
                      )



# Add some more colData columns like condition and replicate number
sce <- sce %>%
  mutate(condition = case_when(str_detect(sample_id, "C") ~ "Control",
                               str_detect(sample_id, "E") ~ "SleepDeprived"
                               )

Ambient RNA detection

Note that Ambient RNA detection should occur before any other filtering (I think even before filtering of non-informative (count 0) genes) because the algorithms rely on being able to model the background distribution of reads.

The classical plot to evaluate whether there may be Ambient RNA in your sample is the Barcode Rank plot that visualizes the total UMI or read counts for each barcode against the barcode’s rank (highest to lowest).

Note that though I’m using all of the samples together to make the plot, according to the OSCA book, we want to run ambient RNA detection tools on each sample separately because each sample will have a unique ambient RNA landscape and the tools (at least many of them) are comparing the total counts for each barcode against the total counts for the suspected ambient RNA population to decide what is an “empty” droplet vs a droplet with the data you want.

This approach utilizes base R to find the total counts and ranks (because DropletUtils wasn’t installing properly for me at first).

Identify doublets for removal

Note that the approach the paper used was to first normalize the data, then find the top variable genes, then compute the doublet density estimate/scores, and using the Griffiths method for thresholding to flag doublets. This mirrors the old scran approach that is now deprecated

  • https://rissolab.github.io/AtlasCortexSD/articles/1_ct_anno.html#doublets-removal
  • https://plger.github.io/scDblFinder/articles/introduction.html#computedoubletdensity

I chose to use this more streamlined approach rather than the approach the paper used for a couple of reasons

  • The paper approach would have required running normalization first (and I can use this opportunity to explain the nuance that some doublet detection tools/methods require that)
  • The tool documentation recommends this approach over the Griffiths method saying it’s the most accurate in their benchmarking
  • I didn’t see any snRNA-seq specific advice

This approach does have a clustering option, but the package maintainers suggest using it if your data very clearly clusters or you’re interested in where the doublets originated from. https://plger.github.io/scDblFinder/articles/scDblFinder.html#should-i-use-the-cluster-based-doublet-generation-or-not

We have a couple of spots so far in the process where we’ve had to make decisions and have a couple of options that will work, but we want to compare these options to decide which one is better for us. This specific comparison isn’t necessarily something that researchers will want to do. And perhaps for the normalization step, looking at the plot to see if there’s a bell curve is enough. But this analysis section is showing how we can find some stats out about our data, and showing how to evaluate those possible combinations / choices. We’re going to use a package named pipeComp for this because we can work with functions rather than scripts.

Put the process together with pipeComp

We’ll focus on combining the normalization and aggregation processes and ask a few questions about the normalized/aggregated data.

What is the highest expressed gene (within the clusters/samples)? What is its observed normalized expression?

For this we’ll want to look at within cluster/sample normalized expression and find the highest value and report that back. We can figure out which gene is the highest across the most number of clusters/samples. We’ll specifically report back the gene name, how many clusters/samples it’s the highest for, and the observed normalized expression value. We’ll call this "max".

How many genes have no observed normalized expression within a cluster/sample?

For this we’ll want to look within cluster/sample normalized expression values and find how many 0s there are. We can find the quartiles across the clusters/samples and report those numbers back (0%, 25%, 50%, 75%, and 100%). We’ll call this "min".

What is the highest observed variance of normalized expression (across the clusters/samples)? Which gene exhibits this amount of variance?

For this we’ll find the variance of each gene’s observed normalized expression across clusters/samples and then return the highest variance observed and which gene has that variance. We’ll call this "variance".

What is the lowest observed median normalized expression (within the clusters/samples)? Which gene is closest to this value?

For this we’ll find the median observed normalized expression value within each cluster/sample. We’ll then find which gene in that cluster/sample that has the closest observed normalized expression. Finally, we’ll pick the lowest value across all the clusters reporting the gene, the median value, and the grouping_id for the cluster or sample that gene was identified for. We’ll call this "median".

We can compare the results of each of these across different combinations of normalization and aggregation.

#' A function to drive the normalization and aggregation process
#'
#' @parameter load_data either TRUE or FALSE. Will load data if TRUE, will run the normalization process if FALSE (unless provided sce has the names associated with the data already)
#' @parameter norm_method either logcounts or deconvolution
#' @parameter sce default is NULL, provide if load_data is FALSE. Should be a SingleCellExperiment object that is filtered but not yet normalized. Should have colData columns `sum` and `sample_id`
#' @parameter aggregation_method either sum or average
#' @parameter aggregation_across either cluster or sample
#' @return sce the SingleCellExperiment object with the newly normalized data saved in either the `logcounts` or `deconvcounts` assay slot


norm_aggregate_data <- function(norm_method, load_data, aggregation_method, aggregation_across, sce = NULL){

  # check parameter inputs
  stopifnot(load_data %in% c(TRUE, FALSE))
  stopifnot(norm_method %in% c('logcounts', 'deconvolution'))
  stopifnot(aggregation_method %in% c('sum', 'average'))
  stopifnot(aggregation_across %in% c('cluster', 'sample'))

  # normalization

  if (load_data){
    sce <- readRDS(here("data/wrangled/sce_norm.rds"))
  } else {
    if (is.null(sce)){
      stop("Must provide an sce object with filtered, unnormalized or normalized data and colData columns `sum` and `sample_id`.")
    }
    if (norm_method == "logcounts"){
      if (!("logcounts" %in% names(assays(sce)))) {
        sce <- scrapper::normalizeRnaCounts.se(sce,
                                           size.factors = sce$sum,
                                           block = sce$sample_id)
      }
    }
    if (norm_method == "deconvolution"){
      if (!("quickClusters" %in% names(colData(sce)) & "deconvcounts" %in% names(assays(sce)))){
        sce$quickClusters <- scran::quickCluster(sce, block = sce$sample_id)
        deconv_sf <- scran::calculateSumFactors(sce, clusters = clusters.block)
        sce <- normalizeRnaCounts.se(sce,
                                 size.factors = deconv_sf,
                                 block = sce$sample_id,
                                 output.name = "deconvcounts",
                                 factor.name = "deconvSizeFactor")
      }
    }
  }

  # aggregation

  if(norm_method == "logcounts"){
    assay_type <- "logcounts"
  } else{
    assay_type <- "deconvcounts"
  }

  if(aggregation_across == "cluster"){
    coi <- "quickClusters"
    if (!coi %in% names(colData(sce))){
      sce$quickClusters <- scran::quickCluster(sce, block = sce$sample_id)
    }
  } else{
    coi <- "sample_id"
  }


  if (aggregation_method == "sum"){
    aggregated <- scrapper::aggregateAcrossCells.se(sce,
                      colData(sce)[[coi]],
                      assay.type = assay_type)
    aoi <- "sums"
  }

  if (aggregation_method == "average"){
    aggregated <- tidySingleCellExperiment::aggregate_cells(sce,
                      .sample = coi,
                      assays = assay_type)
    names(assays(aggregated)) <- "averages"
    aoi <- "averages"
  }

  return (assays(aggregated)[[aoi]])
}

#' A function to grab a specific descriptive stat or metric about the normalized and aggregated data
#'
#' @parameter agg_data the aggregated data
#' @parameter sce Should be a SingleCellExperiment object that is filtered but not yet normalized. Should have colData column `sample_id` or `quickClusters`
#' @parameter aggregation_method either sum or average
#' @parameter aggregation_across either cluster or sample
#' @parameter metric either max, min, variance, or median
#'
#' @return if metric is max the gene ID for the highest expressed gene (seen in the most aggregation_across) (as well as its expression)
#'         if metric is min the average number of genes with no observed expression across the aggregation_across
#'         if metric is variance the gene ID for the highest variance gene for variance across the aggregated clusters or samples (as well as its expression)
#'         if metric is median the gene ID associated with the least median expression observed (as well as the median expression)
#'

grab_metric <- function(agg_data, metric){

  stopifnot(metric %in% c('max', 'min', 'variance', 'median'))

  col_names_res <- c("gene", "gene_count", "gene_avg",
                     "0%", "25%", "50%", "75%", "100%",
                     "median_value", "grouping_id",
                     "variance")

  if (metric == "max"){
    result <- apply(agg_data, 2, function(col) {
      c(gene = rownames(agg_data)[which.max(col)], max_value = max(col))
    }) %>%
      t() %>%
      as.data.frame() %>%
      group_by(gene) %>%
      summarize(gene_count = n(),
                gene_avg = mean(as.numeric(max_value))) %>%
      slice_max(gene_count, n = 1, with_ties = FALSE)

  }

  if (metric == "min"){
    result <- colSums(agg_data == 0) %>% quantile() %>% t() %>% as.data.frame()
  }

  if (metric == "variance"){
    result <- apply(agg_data, 1, var) %>%
      as.data.frame() %>%
      slice_max(as.numeric(`.`), n = 1, with_ties = FALSE) %>%
      dplyr::rename(., variance = `.`) %>%
      mutate(gene = rownames(.))
  }

  if (metric == "median"){
    result <- apply(agg_data, 2, function(col) {
      # Calculate the standard median
      med_val <- round(median(col),2)

      # Find the row index of the value closest to the median
      gene <- rownames(agg_data)[which.min(abs(col - med_val))]

      c(gene = gene, median_value = med_val)
    }) %>%
      t() %>%
      as.data.frame() %>%
      mutate(grouping_id = as.factor(row_number())) %>%
      slice_min(as.numeric(median_value), n = 1, with_ties = FALSE)
  }

  missing_cols <- setdiff(col_names_res, colnames(result))
  result[missing_cols] <- NA

  return(list(result))

}
